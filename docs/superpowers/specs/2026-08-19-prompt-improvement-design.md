# 狼人杀提示词体系改进设计

日期：2026-08-19
状态：已与用户逐节确认
范围：`src/game.ts` 中全部 LLM 提示词 + 两处轻量引擎配合改动（方案 B）

## 1. 背景与目标

### 1.1 已确认的痛点

行为质量：
- 发言模板化/同质化
- 身份感缺失（狼不像狼、民不像民）
- 跟风/无对抗性
- 记忆/一致性差（跨天自相矛盾）

平衡性：
- Day1 票型过度集中
- 改票机制形同虚设（漏声明 `changed_vote` 即作废）/ 平票直接流局

### 1.2 已确认的设计意图（现状基线）

| 模块 | 确认的意图 |
|------|-----------|
| 两轮投票 | 模拟真实对局：私下初投 → 公开票型 → 终投博弈 |
| 风格卡 | 可接受重新设计（含每人独立人设） |
| 发言约束 | 防幻觉是核心，evidence《引用》命中机制保留并强化 |
| 夜晚击杀 | 策略性击杀（选威胁最大的目标） |
| GM 摘要 | 中立事实汇总，无立场 |

### 1.3 根因分析

| 现象 | 提示词侧根因 |
|------|-------------|
| 发言模板化 | 8 人共用 4 张风格卡且只描述投票行为；系统提示人人相同；保底发言模板腔；≤120 字太紧 |
| 身份感缺失 | 狼人无伪装策略指引；村民无目标陈述；缺阵营目标块 |
| 跟风/无对抗 | 无答辩机制（被指控后无需回应）；GM 摘要成为共同锚点 |
| 记忆/一致性差 | 每次调用无状态；任务未注入"你昨天的发言/终投"；`playerObservations` 为 30 字正则截取 |
| Day1 票型集中 | 摘要锚定 + 一句弱指令"不要盲目跟风" |
| 改票形同虚设 | `changed_vote` 声明 + `why_change≥5字` 否则作废（校验补丁绑架博弈设计）；反共识税关键词黑名单误伤 |
| 错位缺陷 | "过于完美的推理可能引起注意"（发言伪装提示）出现在夜晚击杀任务中 |

## 2. 方案选择

- 方案 A（纯提示词改写）：治不了跨天失忆与改票作废，天花板低
- **方案 B（选定）：提示词全面重写 + 若干轻量引擎改动（vote_result 事件、记忆注入、改票判定简化、反共识税类型标记、votingStyles 移除）**，全部为"喂数据/拆补丁"性质，不改变对局流程
- 方案 C（机制大重构：平票 PK、狼队合谋等）：超出本次范围

已知限制（不在本次范围）：平票仍然无人处决、狼队夜晚仍为独立决策多数决。

## 3. 设计详节

### 3.1 玩家系统提示重设计（`PLAYER_SYSTEM_TEMPLATE`）

替换 `VOTING_STYLE_CARDS`（4 种投票风格、8 人套用）为 `PERSONA_CARDS`（8 张独立人设卡，按座位固定分配）。每张卡包含：

- 性格名 + 背景一句话
- 说话方式（语气/句式/口头禅，使 8 人发言天然异质化）
- 投票倾向（继承原 4 种倾向语义，两人可共享倾向但口吻完全不同）

人设与身份（狼/民）正交，防止人设泄露身份。

新增两个块：

1. 阵营目标块（按角色注入）：
   - 村民：在天亮前的投票中放逐所有狼人；唯一的武器是逻辑和投票
   - 狼人：活到狼人数 ≥ 村民数；白天伪装成村民、误导放逐方向、暗中保护队友
2. 身份策略手册（按角色注入，只给原则不给剧本）：
   - 狼人：绝不主动指控队友；队友被围攻时质疑"证据"而非硬洗白；被指控时反打证据最弱者；不当全知神探，适度暴露推理盲区
   - 村民：发言必须有立场；警惕"推理过于完美者"与"从不表态者"；被冤枉时据理力争

保持不变：未知信息规则（防幻觉）、"我"锚点、禁自我指控、JSON 输出字段集合。

引擎配合：`GameState.votingStyles` 字段移除（连带 `coerceState`、`createNewGameState` 更新）。

### 3.2 白天发言提示重设计

1. 答辩机制（核心新增）：发言前扫描当天已有发言，若有人指控当前玩家，注入"⚠️ 今天 SeatX 指控了你：（原文）。你必须在发言中正面回应（解释/反驳/反打），不能装没看见。"
2. 字数放宽：≤120 字 → ≤180 字；结构引导为"结论 → 一条《引用》证据 → 回应指控（如有）"，同时明确"表达方式必须符合人设，禁止套用固定句式"
3. 狼人白天注入：将错位的"过于完美的推理可能引起注意"移到此处，并扩充为狼人白天生存策略 3 条（策略手册的运行时提醒）
4. 观察对象升级：发言 JSON 新增可选 `focus` 字段（≤20 字，"接下来重点观察…"），替代 30 字正则截取；模型未输出时回退现有正则
5. 保底发言去模板化：按人设口吻预设 2-3 个变体随机选用

### 3.3 夜晚击杀提示重设计

任务重写为威胁评估决策：

- 击杀优先级（从高到低）：
  1. 发言最有说服力、正在带偏狼方节奏的好人
  2. 票型/言论上最可能投狼的玩家
  3. 几乎无人怀疑的"干净牌"（留着高嫌疑者背锅）
- 输出 target + 一句击杀理由（content）
- 删除错位提示（已移至 3.2）
- 注入上下文：昨日被处决者身份（若有）、当前存活、队友、自己的观察对象

机制不动：两只狼独立决策 → 多数决 → 平票取小号。

### 3.4 两轮投票提示 + 改票判定简化

第一轮（私下初投）：
- 保留 GM 摘要，加定调语："以下是事实汇总，不是投票指引——先形成你自己的判断，再对照它"
- Day1 额外注入："Day1 信息天然稀少，投票分散是正常且健康的，无需急于站队"

反共识税重构（替换 `HERD_EVIDENCE_HINTS` 关键词黑名单）：
- `buildVoteEvidenceFacts` 为每条事实打类型标记（speech / death / vote_distribution）
- "独立证据"新定义：至少一条 evidence 的《引用》命中"发言或死亡类"事实且指向该目标
- 效果：只引票型的跟票被拦截；引用了目标言行的正常集中票放行

第二轮（终投）：
- 定调改为博弈语言："这是最后的表态机会。你可以加入多数放逐嫌疑人，可以另立山头，可以为人辩护——但必须给出你自己的理由"
- 改票判定简化（引擎配合）：`changed_vote` 由前后 target 自动推导（复用现有 `actualChanged`）；删除"漏声明作废"与 `why_change≥5字` 硬校验；`why_change` 降级为可选公示字段，提示词仅建议"改票时说明理由（将公示）"

### 3.5 GM 摘要提示（微调）

保持中立事实汇总定位。收紧措辞：

- 按玩家逐行陈述：点名怀疑了谁、支持/反对了谁、是否给出理由
- 显式禁止"建议关注""最可疑"等倾向性措辞
- 保持 ≤6 行、温度 0.2、失败降级本地规则摘要不变

### 3.6 记忆注入（引擎配合）

新增 `buildPlayerMemory(state, playerName)`，在发言/投票任务中注入：

```
## 你的历史（只有你自己知道）
- 你昨天的发言："..."
- 你昨天的终投：SeatX（改票：是/否）
- 你声明的观察对象：...
- Day ≥ 2 时提示："你今天的发言不能与昨天自相矛盾"
```

数据来源：
- 昨日发言：`publicEventLog` 中 speech 事件（已存在）
- 昨日终投：**新增 `vote_result` 公开事件**——白天 resolve 阶段写入（含每人终投目标，真实对局中终投本就公示）；同时自动进入"可核查公共事实"，供所有人引用历史票型

### 3.7 校验/保底调整

保留：JSON 解析多层兜底、evidence《引用》命中校验、自我指控禁令、target 合法性、发言≥1/投票≥2 条证据、纠错重试一次流程。

删除：`isValidVoteChange` 硬校验及对应提示词约束；`HERD_EVIDENCE_HINTS` 黑名单。

新增：反共识税新判定（3.4）；speech JSON 可选 `focus` 字段解析。

## 4. 错误处理

- 模型调用失败/超时：沿用现有重试与保底路径（夜晚随机修正、发言保底、弃票降级、终投沿用初投）
- 记忆块缺失（Day1、数据缺损）：整块省略，不影响主流程
- `vote_result` 事件缺失（旧对局 state）：记忆构建器静默跳过终推行

## 5. 测试与验证

2. `npx wrangler deploy --dry-run`（打包/绑定校验）
3. 本地或线上完整对局 2-3 局，检查 timeline 指标：

   - 终投改票人数 > 0（历史为 0）
   - "已降级为保底""二次输出仍违规"次数应显著减少
   - 跨天自相矛盾（人工抽查昨日发言 vs 今日发言）
   - 8 人发言口吻差异（人工抽查）
